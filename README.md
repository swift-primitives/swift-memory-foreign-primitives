# swift-memory-foreign-primitives

`Memory.Foreign` — the foreign regime leaf: the owning envelope around the ecosystem's non-owning raw descriptor (`Span.Raw.Mutable` + provider-supplied finalizer + `~Copyable` uniqueness). It represents the third ownership regime — memory this process did not allocate, owned past the lending scope, released by invoking the provider's callback, never by `deallocate` — the pattern every production datapath converges on (FreeBSD `m_ext_free_t`, Linux `skb` destructors, DPDK external-buffer callbacks, io_uring provided-buffer re-provision), with move-only uniqueness replacing the hand-maintained refcount so exactly-once release is structural. Its entire tower integration is the `Memory.Region` conformance; release semantics stay in the regime's own `deinit`. Deliberately non-`Sendable`: isolation crossing is region-checked `consuming sending` per [MEM-SEND-010]/[MEM-SEND-012]/[MEM-SEND-013]. Design: `swift-institute/Research/memory-foreign-and-memory-protocol.md` (v1.1.0, RECOMMENDATION); instantiation evidence: `swift-buffer-ring-primitives/Experiments/foreign-region-tower-instantiation/` (V1–V5).
